API

Backend API

main.py · FastAPI on Render

EP-01

POST /shortlist

Requires a session. Kicks off the Shortlist Agent as a background task.

EP-02

GET /candidates

Returns the signed‑in user’s saved companies only.

EP-03

POST /reject

Marks a company rejected, enforces the free‑tier cap, queues a replacement search.

EP-04 legacy

POST /matcher

Live job‑posting verification — calls Company Matcher directly, no auth, no persistence.

EP-05 legacy

POST /recommend

One‑shot call into Company Recommender, no auth, no persistence.

EP-06 legacy

GET /demo · /recommend‑demo

Server‑rendered test pages for EP‑04/05, still reachable, not linked anywhere.

AGT

Agents & skills

The reasoning layer — each card’s tags are the tools it calls

AG-01

Shortlist Agent

shortlist_agent.py — observe / think / act / check loop that drives a full search to completion.

  • pick search angle
  • dedupe by scope key
  • retry w/ backoff
  • rank by fit
  • send digest email
AG-02

Company Recommender

company_recommender.py — the actual research step, one Claude tool‑use loop per angle.

  • web_search
  • ATS‑domain fallback
  • jobs_url cache lookup
  • JSON output schema
AG-03 legacy

Company Matcher

company_matcher.py — standalone, verifies a live posting exists before recommending. Not wired into AG‑01.

  • web_search
  • live verification rounds
AG-04

Scout Agent

scout_agent.py — builds and sends the weekly digest on its own schedule, independent of the live API.

  • digest compose
  • Gmail send

Flow sequences

The same map, read as the paths data actually takes. Codes link back to the cards above.

01

Sign in

PG-07→ EX-04→ DB-05→ session shared — PG-08 PG-09 PG-10 Verification is button‑gated (not on page load) so an email scanner can’t burn the one‑time link before the real click.
02

Run a shortlist search

PG-08→ EP-01→ AG-01→ AG-02→ EX-01+EX-02→ DB-01→ EX-03→ PG-08 Loops until 10 unique companies are saved, then ranks, emails the digest, and the page re‑polls GET /candidates.
03

Reject & replace

PG-08→ EP-03→ AG-01→ AG-02 count=1→ DB-01 Capped at 5 rejections per search scope; replacement inherits the original resume, role and Advanced options.
04

Track an opening

PG-09→ DB-02 Direct client‑to‑Supabase, no backend hop — RLS scopes rows, Realtime pushes changes back to every open tab.
05

Contact form

PG-04→ DB-03 Anon insert, no session required.
06

Admin review

PG-10→ DB-05→ DB-03+DB-04
07

Weekly digest (automated)

CR-01→ AG-04→ EX-03 Fully decoupled from every page and from EP‑01–03.
08

Legacy matcher (unlinked)

EP-04→ AG-03 ··· EP-05→ AG-02 No page links here and neither path touches DB‑01 — results are returned inline, never saved.
